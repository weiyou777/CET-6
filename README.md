# 英语六级真题题库 · 使用说明

## 文件结构
```
英语六级/
├── 英语六级真题题库.html      ← 主程序（双击用浏览器打开）
├── app.js                     ← 应用逻辑（与 html 同目录，勿单独移动）
├── data_writing.js            ← 写作题库（24 题，2016–2025 真题话题）
├── data_translation_a.js      ← 翻译题库 A（2015–2022）
├── data_translation_b.js      ← 翻译题库 B（2019–2025，共 70 套真题源文）
├── data_reading.js            ← 阅读题库（7 篇，含 2024.6 真题全文 + 单题精练 + 模拟）
├── data_listening.js          ← 听力题库（2 篇真题原文跟读）
└── 资源合集/
    ├── 00-资源导航.md          ← 网盘/官网/学习站总索引
    ├── 01-提分策略详解.md      ← 全题型高分策略（完整版）
    ├── 02-高频词汇与翻译模板.md← 翻译主题词 + 万能句式
    ├── 03-写作模板与句型.md    ← 写作模板 + 句型库
    └── 04-真题来源与版权说明.md← 来源与版权
```

## 快速开始
1. 双击 `英语六级真题题库.html` 用浏览器（Chrome / Edge 推荐）打开。
2. **首次使用**：首页可「导入之前的缓存文件」，或直接点「开始在线练习」。
3. 选择题型（写作/翻译/阅读/听力）→ 可按分类/年份筛选 → 设定每组的题数 → 开始。
4. 客观题（阅读/听力）自动判分；写作/翻译/听力跟读由你**自评对错**，系统均记录。
5. 每组结束生成报告；随时在「错题本」「分析报告」查看薄弱点与正确率。

## 数据缓存（重点）
- 所有记录保存在**本浏览器 localStorage**（键名 `cet6_cache_v1`），不上传任何服务器。
- **关闭程序时**会自动导出一份缓存 JSON 到浏览器「下载」文件夹（文件名含日期时间）。
- 在「数据管理」页可随时**手动导出**或**导入**缓存文件，实现跨设备/长期进度追踪。
- 建议把导出的 `.json` 与上面的文件放在一起，方便下次「导入缓存」恢复。

## 关于真题与资源
- 题库为对近 10 年公开真题的**搜集、去重、归纳、提炼**，翻译含 70 套真题源文与参考译文，写作含 24 个真题话题与框架。
- 听力因版权与音频格式限制，以「真题原文跟读 + 题目自测」形式呈现；完整音频请通过「资源导航」中的网盘/可可英语获取并配合训练。
- 完整官方 PDF/音频真题的网盘链接见 `资源合集/00-资源导航.md`（需自行用网盘客户端保存，提取码见该文件）。
- 真题版权归全国大学英语四、六级考试委员会所有，本合集仅用于个人学习。
